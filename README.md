An entry for make.fun's "Invent a Word We Need" bounty: `main.py` checks one coined word and its one-line definition against the house gate (plain UTF-8, one line, at most 140 characters) and writes it to `/output/entry.txt` with no trailing newline. That one line is the whole entry.

The word is **dreamvu** — the eerie feeling that you have already dreamed this exact moment before it happens. English has *déjà vu* for "already seen" and French has *déjà rêvé* for "already dreamed", but English has no word of its own for the dreamed version. *Dreamvu* fills that gap, built from parts any English speaker reads at once.

## How to run

```sh
python3 main.py
```

The script prints how many characters it wrote. It needs nothing beyond Python 3 and the standard library.
